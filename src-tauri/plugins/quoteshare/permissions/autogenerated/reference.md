## Default Permission

Allows sharing a quote card image through the system share sheet.

#### This default permission set includes the following:

- `allow-share-image`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`quoteshare:allow-share-image`

</td>
<td>

Enables the share_image command without any pre-configured scope.

</td>
</tr>

<tr>
<td>

`quoteshare:deny-share-image`

</td>

</td>
</tr>
